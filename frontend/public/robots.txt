# SEO-1b (22/09/2026) — ADRESSES PERSONNELLES : `noindex`, ET SURTOUT PAS
# `Disallow`. Le premier jet interdisait ici /espace/, /duo/, /parrainage et
# /checkout tout en posant un `noindex` sur la page. Les deux ensemble
# s'annulent : un robot qui n'a pas le droit de CHARGER la page ne lit jamais
# la balise qui lui demande de ne pas l'indexer — et l'adresse peut rester
# indexee « sans description ». Ces quatre chemins restent donc CRAWLABLES,
# et c'est leur `noindex, nofollow` (api/server.py, `_serve_spa`) qui les tient
# hors de l'index. Rien de secret n'y est servi au robot : le contenu vient
# d'appels authentifies. La securite, elle, n'est pas dans ce fichier — elle
# est dans l'authentification et les jetons.
#
# Les regles ci-dessus sont HISTORIQUES et laissees telles quelles.
# `/reset.html` et `/pwa-diag.html` sont de vrais fichiers, servis tels quels
# (aucune balise ne peut y etre posee) : pour eux, ce fichier est la seule
# regle, et il n'y a donc aucun conflit.
